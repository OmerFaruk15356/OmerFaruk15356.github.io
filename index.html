    Where I'm most useful on a project.

    Drawn from what I've actually shipped, not a wish list.

    Multiplayer networking

    Photon Fusion 2 and PUN2 — lobby and matchmaking flows, server-authoritative game logic over RPC, host migration, state sync that survives mid-match joins and disconnects.

    Gameplay systems

    Player controllers as state machines, ability systems, interaction layers behind a shared interface, data-driven content with ScriptableObjects so balance changes don't touch code.

    Game feel

    Coyote time, input buffering, separate rise and fall gravity, placement and line-clear effects, camera shake — driven by a single tunable config asset instead of scattered magic numbers.

    Editor tooling

    Scene-view tools for level designers: dragging bezier control points, adding and removing curve segments, smoothing paths — all without opening a script.

    Backend & publishing

    Unity Cloud Code economy and progression services, Firebase integration, Google Play Games sign-in, and Google Play Console release setup.

    Performance on low-end Android

    Texture compression, sprite atlasing, and holding a frame budget on the devices most players actually own rather than in the editor.
