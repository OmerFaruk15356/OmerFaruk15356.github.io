# omerfaruk15356.github.io

Personal portfolio — Unity / C# game developer.

Single static page, no build step. `index.html` holds the markup, styles and the
`PROJECTS` array that renders the Work grid and every project detail view.

- `index.html` — the whole site
- `shots/` — project screenshots
- `files/` — downloadable CV
- `og.png` — link preview card

To add or edit a project, edit the `PROJECTS` array near the bottom of `index.html`.
